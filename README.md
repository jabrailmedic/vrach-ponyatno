# Клиническая практика — виртуальный пациент

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/jabrailmedic/vrach-ponyatno)

**Быстрый запуск:** нажми кнопку Deploy to Render выше, войди в Render и подтверди создание сервиса. После развёртывания добавь в настройках сервиса переменную `OPENAI_API_KEY`, чтобы заработал виртуальный пациент. Ключ нельзя публиковать в GitHub или передавать в чат.

Серверное веб-приложение для учебной отработки клинического мышления: студент самостоятельно собирает анамнез, назначает исследования, формирует план лечения и клиническое заключение.

## Состав проекта
- Node.js + Express
- Виртуальный пациент через OpenAI Responses API
- Сценарий пациента хранится на сервере в `data/case.js`
- Сессии сохраняются в SQLite
- Интерфейс на HTML/CSS/JavaScript

## Переменные окружения
- `OPENAI_API_KEY` — ключ API, хранить только в переменных окружения хостинга
- `OPENAI_MODEL` — необязательная модель, по умолчанию `gpt-4.1-mini`
- `PORT` — порт, задаётся хостингом

## Локальный запуск
Node.js 20+:
```sh
npm install
npm start
```

## Важно
Это учебный MVP, а не медицинская информационная система и не инструмент для принятия реальных клинических решений. До публичного использования необходимы авторизация и разграничение доступа к сессиям, безопасное хранение данных, резервное копирование, тестирование и клиническая валидация сценариев. SQLite требует постоянного дискового тома; на бесплатном тарифе без постоянного диска данные могут теряться при пересоздании экземпляра.
